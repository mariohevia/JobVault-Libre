Installing on Linux

Three steps, no root required for most setups.

01

Download the latest release

Use the button above, or grab it directly from the GitHub Releases page. Check the release notes for the exact file to grab for your distribution.

02

Make it executable

If the download doesn't already have execute permissions, set them from a terminal:

# from the folder you downloaded it to
chmod +x JobVault-Libre*
03

Run it

Double-click the file in your file manager, or launch it from the terminal. JobVault Libre creates its local data file on first run. No setup screens, no accounts.

Packaging is still evolving release to release. If something doesn't run as expected on your distribution, please open an issue on GitHub — it helps the next person too.
Prefer to build it yourself

Run it from source, on any platform.

JobVault Libre is a Python / PyQt6 application. If you're comfortable with a terminal, the build instructions in the repository walk through setting up a local copy on Linux, Windows, or macOS today.
